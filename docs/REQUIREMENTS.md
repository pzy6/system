# 银发守护者系统 — 软件需求规格说明书

## 1. 项目概述

银发守护者系统是一个面向养老院的 AI 视觉监护系统，通过多路摄像头实时监测老人状态，
实现摔倒检测、烟雾检测、异常行为识别和人脸身份识别。

**版本**: 2.0.0  
**目标用户**: 养老院护理人员、管理人员

## 3. 功能需求

### 3.1 视频监控
- 支持 USB 摄像头和 RTSP 网络摄像头
- 最多 4 路同时监控，2×2 网格显示
- 自动重连，断线 5 秒内恢复
- 显示实时 FPS 和摄像头状态

### 3.2 摔倒检测
- 基于 YOLOv11n-pose 17 关键点姿态估计
- 规则引擎：垂直角度 + 宽高比 + 踝髋倒置 + 运动速度 加权评分
- 摔倒置信度 ≥ 0.75 触发告警
- 告警包含：截图 + 前后 8 秒视频片段

### 3.3 人脸检测与身份识别
- YOLOv8n (WIDER Face 预训练) 检测人脸
- insightface ArcFace 提取 512 维嵌入
- 与 `data/face_db/` 中已注册人脸余弦相似度匹配
- 相似度 < 0.6 标记为陌生人
- 支持通过 `scripts/enroll_face.py` 注册新身份

### 3.4 烟雾/火焰检测
- YOLOv11n (Home Fire 数据集训练, mAP50 89.7%)
- 检测 fire + smoke 双类
- 置信度 ≥ 0.5 触发告警

### 3.5 异常行为分析
- 质心跟踪 + 规则引擎
- 5 类异常：滞留(>1200帧)、徘徊、剧烈运动(>50px/帧)、静止不动(>300帧)、跌倒未恢复(>120s)
- 置信度 ≥ 0.7 触发告警

### 3.6 告警管理
- 4 种告警类型：跌倒/烟雾/陌生人/异常行为
- 告警倒序显示，最多 100 条
- 每条告警关联截图 + MP4 视频片段
- 告警状态：unhandled → handled
- 告警历史持久化到 `data/alarms/alarm_history.jsonl`

## 4. 非功能需求

### 4.1 性能
| 指标 | 目标 | 测量方法 |
|------|------|----------|
| 端到端 FPS | ≥ 10 (4 核 CPU) | process_frame 计数器 |
| 摔倒检测延迟 | < 300ms (事件发生到告警) | 时间戳差值 |
| 人脸识别延迟 | < 200ms/帧 | 计时器 |
| CPU 占用 | < 80% (i7-14700HX) | 系统监控 |
| 内存占用 | < 2GB | 系统监控 |

### 4.2 可靠性
- 模型缺失时自动降级：YOLO→PyTorch→ONNX→Haar Cascade/HOG
- 摄像头断开 5 秒内自动重连
- 队列满时丢弃最旧帧，避免内存溢出
- 7×24 小时连续运行不崩溃

### 4.3 安全性
- 人脸数据本地存储，不上传云端
- 配置文件敏感信息（RTSP 密码）建议加密
- 操作日志记录所有人机交互

### 4.4 可维护性
- 日志滚动保存（默认 10MB × 5 个文件）
- 配置热加载（修改 config.yaml 后重启生效）
- 模型版本记录在 VERSION 文件
